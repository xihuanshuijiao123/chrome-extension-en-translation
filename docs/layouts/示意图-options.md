# Options 设置页面 — 布局设计与实现步骤

> 对应文档：[proposal.md](../proposal.md) 3.3 / [design.md](../design.md) 4.5
> 定位：插件设置页，配置 AI 模型服务（OpenAI 兼容，默认 Qwen），界面简约。

## 1. 页面职责

- 配置 API Key、Base URL、模型名称。
- 保存配置到本地存储（仅用于 Background 层调用翻译接口）。
- 提供保存成功 / 失败反馈。

## 3. 功能模块与布局设计

### ① 顶部标题栏

```
┌──────────────────────────────────────┐
│  ⚙ 设置 · AI 模型配置               │
└──────────────────────────────────────┘
```

- 固定展示页面标题，明确页面用途。

### ② 配置表单区

```
┌──────────────────────────────────────┐
│  API Key     [ •••••••••••••••• ]    │
│  Base URL    [ https://.../v1 ]      │
│  模型名称    [ qwen-plus        ▼ ]  │
└──────────────────────────────────────┘
```

- **API Key**：密码输入框，内容打码显示；为安全考虑不预填明文（留空表示不修改）。
- **Base URL**：文本输入框，默认值为 Qwen（DashScope）的 OpenAI 兼容端点。
- **模型名称**：下拉选择 + 可输入，内置 Qwen 常见模型（如 `qwen-plus`、`qwen-turbo`、`qwen-max`），允许自定义模型名。

### ③ 说明提示区

```
┌──────────────────────────────────────┐
│  💡 提示: 采用 OpenAI 兼容协议, 修改  │
│     Base URL 与模型名即可切换服务商。 │
└──────────────────────────────────────┘
```

- 静态提示文案，说明协议兼容性与切换模型的方式。

### ④ 操作区

```
┌──────────────────────────────────────┐
│          [ 💾 保存配置 ]             │
└──────────────────────────────────────┘
```

- 单个「保存配置」按钮，提交表单前进行必填校验（API Key 为空且首次保存时给出提示）。

### ⑤ 状态反馈区

```
┌──────────────────────────────────────┐
│  ● 状态: 未修改 / 已保存 ✓ / 保存失败 ✗│
└──────────────────────────────────────┘
```

- 保存成功显示绿色「已保存」；失败显示红色原因（如网络无关的本地校验失败）。

## 4. 实现步骤（按模块）

### 阶段一：页面骨架

1. 搭建 Options 页面入口（React 挂载、全局样式、单列居中布局）。

### 阶段二：配置表单（②）

2. 实现 API Key / Base URL / 模型名称三个输入控件，及表单值状态管理。
3. 页面加载时从 `storage.local` 读取已有配置并回填（API Key 不回填明文）。
4. 实现必填校验与默认值（Base URL 指向 Qwen OpenAI 兼容端点，模型默认 Qwen 系列）。

### 阶段三：保存逻辑（④⑤）

5. 实现「保存配置」：写入 `storage.local` 的 `config` 键。
6. 实现状态反馈：保存成功 / 失败提示。

### 阶段四：联动校验（与 Popup 配合）

7. 配置保存后，Popup 侧「一键翻译」前校验是否已配置 API Key，未配置时提示跳转本设置页。
