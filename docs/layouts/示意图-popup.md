# Sidebar 页面 — 布局设计与实现步骤

> 对应文档：[proposal.md](../proposal.md) 3.4 / [design.md](../design.md) 4.4
> 定位：插件主界面，以 Firefox 浏览器**右侧边栏**形式呈现（高度撑满整个浏览器窗口，宽度由浏览器侧边栏机制控制、用户可拖拽调整），承载「一键翻译」与「下载译文」两大核心操作，界面简约，无冗余功能。

## 1. 页面职责

- 一键提取当前页面文章并翻译。
- 以打字机效果动态展示翻译结果（经 md-wx 渲染）。
- 提供下载译文（Markdown 文件）、停止翻译、进入设置等必要操作。
- 打开时恢复本地最近一次翻译结果。
- 载体为 Firefox 侧边栏：点击工具栏插件图标即可打开 / 关闭，界面高度撑满浏览器窗口，便于长文阅读。

## 2. 页面整体布局（ASCII）

```
┌──────────────────────────────────────────────────┐
│  浏览器窗口（侧边栏固定于右侧、高度撑满全窗口）     │
│  ┌────────────────────┐  ┌──────────────────────┐ │
│  │                    │  │  📄 文章翻译  ⚙ 设置  │ │ ← ① 顶部栏
│  │   当前网页内容      │  ├──────────────────────┤ │
│  │   （正常浏览）      │  │      ✨ 一键翻译      │ │ ← ② 翻译操作区
│  │                    │  ├──────────────────────┤ │
│  │                    │  │ 标题:  <文章标题>     │ │ ← ③ 文章信息区
│  │                    │  │ 作者:  <作者名>       │ │
│  │                    │  │ 原文:  <原文链接>     │ │
│  │                    │  ├──────────────────────┤ │
│  │                    │  │ [翻译正文 · md-wx]    │ │ ← ④ 内容展示区
│  │                    │  │ (打字机效果 · 全高滚动)│ │
│  │                    │  ├──────────────────────┤ │
│  │                    │  │ [ ⏹ 停止 ][ ⬇ 下载 ] │ │ ← ⑤ 底部操作栏
│  │                    │  ├──────────────────────┤ │
│  │                    │  │ ● 状态: 就绪/翻译中/..│ │ ← ⑥ 状态提示区
│  └────────────────────┘  └──────────────────────┘ │
└──────────────────────────────────────────────────┘
```

## 3. 功能模块与布局设计

### ① 顶部栏

```
┌──────────────────────────────────────┐
│  📄 文章翻译            ⚙ 设置       │
└──────────────────────────────────────┘
```

- 左侧：插件名称（固定展示）。
- 右侧：设置图标入口，点击打开 Options 设置页。

### ② 翻译操作区（核心）

```
┌──────────────────────────────────────┐
│        ┌─────────────────┐           │
│        │  ✨ 一键翻译     │           │
│        └─────────────────┘           │
└──────────────────────────────────────┘
```

- 默认状态：居中大按钮「一键翻译」，为整页视觉焦点。
- 翻译进行中：按钮切换为「⏹ 停止翻译」，用于中断流式输出。
- 已存在翻译结果时仍可重新触发翻译（覆盖旧结果）。

### ③ 文章信息区

```
┌──────────────────────────────────────┐
│  标题:  <文章标题>                   │
│  作者:  <作者名>                     │
│  原文:  <原文链接>                   │
└──────────────────────────────────────┘
```

- 展示提取到的文章元信息，对应需求输出格式的头部（标题 / 作者 / 原文链接）。
- 元信息缺失时对应行隐藏。

### ④ 内容展示区

```
┌──────────────────────────────────────┐
│  [翻译后的正文 · md-wx 渲染]         │
│  (打字机效果 逐字/逐段 动态输出)     │
└──────────────────────────────────────┘
```

- 占据侧边栏主要高度（撑满整个浏览器窗口全高），支持滚动。
- 翻译增量内容实时传入 md-wx 的 `MarkdownRenderer` 渲染，形成打字机效果。
- 渲染严格遵循需求文档 §3.5 输出格式：
  - 第一行为 `# [文章标题]`。
  - 引用块列出 `>**作者**:` 与 `>**原文链接**:`。
  - 其后为翻译后的正文。

### ⑤ 底部操作栏

```
┌──────────────────────────────────────┐
│  [ ⏹ 停止 ]      [ ⬇ 下载译文 ]     │
└──────────────────────────────────────┘
```

- 「停止」：仅翻译过程中可见，中断本次翻译。
- 「下载译文」：仅翻译完成后可见，将翻译结果（含标题/作者/链接/正文的完整 Markdown）下载为 `.md` 文件，文件名取自文章标题。

### ⑥ 状态提示区

```
┌──────────────────────────────────────┐
│  ● 状态: 就绪 / 翻译中 / 已完成 / 错误│
└──────────────────────────────────────┘
```

- 常驻底部，以不同颜色区分：就绪（灰）、翻译中（蓝）、已完成（绿）、错误（红）。
- 错误时展示可读提示（如「未识别到文章内容」「请先配置 API Key」），并引导操作。

### 页面状态切换关系

| 状态           | 翻译按钮       | 停止 | 下载 | 内容区         |
| -------------- | -------------- | ---- | ---- | -------------- |
| 就绪（无结果） | 一键翻译       | 隐藏 | 隐藏 | 空/占位        |
| 翻译中         | 显示为「停止」 | 显示 | 隐藏 | 打字机增量输出 |
| 已完成         | 一键翻译       | 隐藏 | 显示 | 完整译文       |
| 错误           | 一键翻译       | 隐藏 | 隐藏 | 错误占位提示   |

## 4. 实现步骤（按模块）

### 阶段一：页面骨架

1. 搭建 Sidebar 页面入口（manifest 配置 `sidebar_action` 声明面板页面；React 挂载、全局样式、容器布局：顶部栏 / 内容 / 底部栏）。
2. 引入 md-wx 依赖并配置样式，验证 `MarkdownRenderer` 可正常渲染。

### 阶段二：非 UI 底层链路（先行打通数据）

3. 实现 Content Script 提取模块：注入页面，用 `@mozilla/readability` 解析文章，返回标题 / 作者 / 正文 HTML。
4. 实现 Content Script 转换模块：用 Turndown 将正文 HTML 转为 Markdown（含图片 `![alt](src)`）。
5. 定义 Sidebar ↔ Content Script ↔ Background 的消息协议（提取请求、翻译请求、流式增量推送）。

### 阶段三：翻译操作区（②）

6. 实现「一键翻译」：请求 Content Script 提取并转换 → 组装需求格式的翻译输入 → 请求 Background 调用 OpenAI 兼容接口（Qwen）流式翻译。
7. 实现「停止翻译」：发送中断消息，结束流式输出并保留已输出部分。

### 阶段四：展示与信息区（③④）

8. 实现文章信息区：绑定标题 / 作者 / 原文链接展示，缺失时隐藏。
9. 实现内容展示区：翻译增量内容逐步追加到 md-wx 渲染，形成打字机效果；完成后整体渲染。
10. 严格校验最终输出格式（一级标题、引用块作者/链接、正文）。

### 阶段五：底部操作栏（⑤⑥）

11. 实现「下载译文」：将完整翻译结果导出为 `.md` 文件下载，文件名取自文章标题。
12. 实现状态提示区：就绪 / 翻译中 / 已完成 / 错误四态切换与错误文案。
13. 实现本地持久化：翻译完成后写入 `storage.local` 的 `lastResult`（整体覆盖）；侧边栏打开时读取并恢复展示。
14. 实现侧边栏开关：Background 监听工具栏图标点击（`browser.action.onClicked`），调用 `browser.sidebarAction.toggle()` 打开 / 关闭右侧侧边栏。
