# Firefox 英文网页翻译插件 — 需求文档

## 1. 项目概述

本插件面向 Firefox 浏览器，帮助中文用户在浏览英文网站时克服语言障碍。用户打开任意英文网页后，可通过一次点击，将当前页面中的主要文章内容自动提取出来，转换为 Markdown 格式，并调用 AI 大模型翻译为中文，最终以类似 ChatGPT 的打字机效果动态展示给用户。

## 2. 目标用户

- 需要频繁阅读英文技术博客、新闻、文档等内容的用户。
- 不希望通过复制粘贴或打开第三方翻译网站来阅读英文文章的用户。

## 3. 核心功能需求

### 3.1 文章内容提取

- 插件应能自动识别并提取当前页面中的「主要文章内容」，过滤掉导航栏、侧边栏、页脚、广告、评论区等无关元素。
- 支持从文章页面中提取以下元信息：
  - 文章标题（若存在）
  - 作者名称（若存在）
  - 原始文章 URL

### 3.2 Markdown 转换

- 提取到的文章内容应被转换为标准 Markdown 格式，包括但不限于：
  - 标题层级（H1/H2/H3 等）
  - 段落
  - 列表（有序与无序）
  - 引用块
  - 代码块
- 原文中的图片必须被转换为 Markdown 图片语法：`![alt](src)`，其中：
  - `alt` 为图片的替代文本（若无替代文本，可为空）。
  - `src` 为图片的源地址。
- 原文中的超链接应被保留为 Markdown 链接语法。

### 3.3 AI 大模型翻译

- 将转换后的 Markdown 原文调用 AI 大模型翻译为中文。
- 翻译时应尽量保留 Markdown 格式结构（标题、列表、代码块、图片等语法不应丢失）。
- 支持用户配置所使用的 AI 模型服务及密钥（如 API Key）。

### 3.4 打字机效果动态展示

- 翻译结果应以类似 ChatGPT 的打字机效果逐字/逐段动态输出，而非一次性整段显示。
- 打字机效果应支持中断与完成后的完整展示。
- 展示界面应美观、可滚动，并便于阅读与复制。

### 3.5 输出内容格式

最终展示给用户的翻译结果必须遵循以下固定格式：

```
# [文章标题]

>**作者**:[作者名]
>**原文链接**:[原始文章URL]

[翻译后的正文]
```

规则说明：

- 标题为 Markdown 一级标题，使用提取到的文章标题。
- 引用块中依次列出作者与原文链接：
  - 若未提取到作者，作者行可省略。
  - 若未提取到原文链接，原文链接行可省略。
- 正文为翻译后的 Markdown 内容。

### 3.6 本地持久化

- 插件无需提供历史记录功能。
- 仅在本地持久化保存用户**最近一次**的翻译结果，覆盖旧的翻译结果，供用户刷新页面或再次打开插件时恢复查看。

## 4. 非功能需求

### 4.1 兼容性

- 仅面向 Firefox 浏览器，基于浏览器扩展标准实现。
- 应兼容 Firefox 当前主流稳定版本。

### 4.2 性能

- 文章提取与 Markdown 转换应在页面加载后快速完成，不应明显卡顿页面。
- AI 翻译请求应支持流式（增量）返回，以支撑打字机效果。

### 4.3 安全性

- 用户的 API Key 等敏感配置应安全地存储在本地，不应以明文形式暴露在页面中。
- 插件应遵循最小权限原则，仅申请实现功能所必需的权限。

### 4.4 可用性

- 用户界面应简洁直观，一键触发翻译；点击工具栏插件图标即可打开 / 关闭右侧翻译侧边栏。
- 提取失败或无文章内容时应给出清晰友好的提示。

## 5. 范围外（本期不做）

- 不提供翻译历史记录与收藏功能。
- 不做划词翻译、页面整页翻译（仅翻译主要文章内容）。
- 不内置 AI 模型服务，需用户配置模型服务与密钥。
- 不提供多语言互译（仅英文 → 中文）。

## 6. 验收标准

- 打开任意一个包含文章的英文网站，点击插件按钮，可正确提取文章标题、作者与正文。
- 提取结果中的图片正确转换为 `![alt](src)` 格式。
- AI 翻译结果按规范格式输出，并以打字机效果动态展示。
- 刷新页面后，插件可恢复展示最近一次翻译结果。
- 重新翻译后，本地存储被更新为最新结果，旧结果被覆盖。
